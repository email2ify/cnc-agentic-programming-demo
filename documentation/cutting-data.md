# Skärdatatabell för CNC-svarvning

| Operation | Skärhastighet (vc) | Matning (f) | Radiellt skärdjup (ap) |
|---|---:|---:|---:|
| **Planing** *(Facing)* | 140 m/min | 0.15 mm/varv | Efter behov |
| **Grovsvarvning** *(Rough turning)* | 140 m/min | 0.25 mm/varv | 1.5–2.0 mm |
| **Finsvarvning** *(Finish turning)* | 160 m/min | 0.10 mm/varv | 0.2–0.4 mm |
| **Spårsvarvning** *(Grooving)* | 100 m/min | 0.08 mm/varv | Verktygsberoende |
| **Gängning M12×1** *(Threading)* | 50–80 m/min | 1.00 mm/varv | Flera skär |
| **Avstickning** *(Parting)* | 80–100 m/min | 0.06 mm/varv | Verktygsberoende |

> **Note:** These are provisional simulation values for carbide tooling and ordinary grey cast iron. Final values must be verified against the exact material grade, insert manufacturer’s recommendations and machine limits.
